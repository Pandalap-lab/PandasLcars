# PandasLcars 0.6.12

- Wolkenansicht mit maximal 24 Prozent Deckkraft und transparenter wolkenfreier Fläche. Ein durchgehendes EUMETSAT-Bild ersetzt unterschiedlich aufgelöste Kacheln; fehlende Daten an der Abdeckungsgrenze werden weich ausgeblendet.
- Wolken- und Blitzzeitangaben stehen in der rechten Kachel und verdecken die Karte nicht mehr.
- Die gemeinsame Saharastaub-/Blitz-Kachel ist kompakter; SYSTEM STATUS erhält wieder mehr Platz und eine Mindesthöhe für alle Messwerte.
- Wetter 3 Tage reserviert eigene Zeilen für die Vorhersage und Quellenangabe.
- Die Updateprüfung verwendet die tatsächliche Programmversion statt der fest hinterlegten Version 0.6.10. Dadurch wird die bereits installierte Version nicht erneut angeboten.

Geprüft werden Dashboard und veröffentlichte Dateien, Installation sowie zweimaliges Upgrade von 0.6.11 mit Erhalt der Einstellungen und verschlüsselten Schlüsseldatei. Die Wolkentransparenz wurde zusätzlich anhand tatsächlicher Bildpixel kontrolliert.

Norton-/SmartScreen-Prüfungen können weiterhin den Start verzögern oder blockieren. Satellitenblitzereignisse sind keine bestätigten Bodeneinschläge.
